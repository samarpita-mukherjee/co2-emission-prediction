Files in this folder are shown automatically on the matching page of the app (in file-name order):
  notes.md        short text (markdown)
  *.csv           a table
  *.png / *.jpg   a figure
Use numbers to set the order, for example: 01_accuracy_by_group.csv, 02_confusion_matrix.png.
The title above each table or figure is made from the file name.
Tips for a screen share: figures with large text (font size 12 or more, 200 dpi), tables with few rows.
